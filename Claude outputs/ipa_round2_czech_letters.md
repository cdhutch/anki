# Czech Letter → IPA Card Data — Round 2

Round 2 card type: front = a Czech letter or digraph, back = the IPA
symbol(s) it represents plus a basic example word. By this round you should
already recognize every IPA symbol from Round 1 (English/German/French/
Russian/Ukrainian) except a handful of genuinely new sounds Czech
introduces — those are flagged below and are your first exposure to them.

## New sounds Czech introduces (not covered in Round 1)

| IPA | What it is | Example |
|---|---|---|
| c | voiceless palatal stop (spelled **ť**) | chu**ť** (taste/appetite) |
| ɟ | voiced palatal stop (spelled **ď**) | **d**ěkuji (thank you) |
| ɲ | palatal nasal (spelled **ň**) — same phone as French "gn" in montagne, if that row helps | ků**ň** (horse) |
| r̝ | raised alveolar trill ("ř") — unique to Czech, no equivalent in any of your other languages | **ř**eka (river) |
| ou̯ | native Czech diphthong, spelled **ou** | m**ou**ka (flour) |

Everything else below reuses a Round 1 sound; the point of Round 2 is just
learning which Czech letter spells it.

## Diphthongs (digraph spellings)

## Context-dependent letters

| Letter | IPA | Rule |
|---|---|---|
| d | d → ɟ before i/í/ě | represents the palatal stop /ɟ/, not plain /d/, when followed by a soft-vowel letter |
| t | t → c before i/í/ě | represents /c/, not plain /t/, in the same environment |
| n | n → ɲ before i/í/ě | represents /ɲ/, not plain /n/, in the same environment |
| x | ks or ɡz | loanwords only; /ɡz/ specifically with the "ex-" prefix |

## Foreign letters

Q, W, X occur only in loanwords and foreign names; as loanwords
naturalize, Q is usually respelled **kv** and W as **v**.

## The hard/soft vowel-pairing rule

Czech spelling requires certain consonants ("soft": ž š č ř c j ď ť ň) to
be followed only by the "soft" vowel letters i/í, and certain consonants
("hard": h ch k r d t n g) to be followed only by the "hard" vowel letters
y/ý — even though i/y and í/ý sound identical. This is purely an
orthographic convention for spelling correctly, not a pronunciation rule —
worth knowing so a Czech word's spelling doesn't look "wrong" to you.
