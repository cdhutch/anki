## Вступ (Introduction)

### 0.1 Українська абетка (The Ukrainian Alphabet)

The 33-letter Ukrainian alphabet: `Аа Бб Вв Гг Ґґ Дд Ее Єє Жж Зз Ии Іі Її Йй Кк Лл Мм Нн Оо Пп Рр Сс Тт Уу Фф Хх Цц Чч Шш Щщ ь Юю Яя`

### 0.2 Голосні та приголосні (Vowels and Consonants)

**Vowels:** А а, Е е, И и, І і, О о, У у, Ю ю, Я я

**Consonants:** Б б, В в, Г г, Ґ ґ, Д д, Ж ж, З з, Й й, К к, Л л, М м, Н н, П п, Р р, С с, Т т, Ф ф, Х х, Ц ц, Ч ч, Ш ш, Щ щ

### 0.4 Відмінки: називний (Cases: Nominative)

**In Ukrainian there are 7 cases:**

| Ukrainian | English |
|---|---|
| Називний відмінок | Nominative case |
| Родовий відмінок | Genitive case |
| Давальний відмінок | Dative case |
| Знахідний відмінок | Accusative case |
| Орудний відмінок | Instrumental case |
| Місцевий відмінок | Locative/Prepositional case |
| Кличний відмінок | Vocative case |

The **nominative case** names things. It is the subject. *Це Україна. Це університет. Це я.* ("This is Ukraine. This is a university. This is me.")

**Personal pronouns: nominative case, accusative case.** *Як Вас звати? → Мене звати Олена.* ("What is your name? → My name is Olena" — literally "Me they-call Olena," accusative case) is the model sentence for learning the nominative → accusative pronoun table, built with the pattern **+ ЗВАТИ + name**.

| Називний відмінок | Знахідний відмінок |
|---|---|
| я | мене́ |
| ти | тебе́ |
| він | його́ |
| вона́ | її́ |
| ми | нас |
| ви | вас |
| вони́ | їх |

### 0.5 Яка Ваша/твоя професія? (What is your profession?)

Table drill: nominative pronoun (я, ти, він, вона, ми, ви, вони) **+ профе́сія** ("+ profession").

### 0.7 Особові займенники: давальний відмінок (Personal Pronouns: Dative Case)

Model question: *Скільки Вам/тобі років?* → *Мені 23 роки.* ("How old are you? → I am 23" — literally "To-me 23 years," dative case).

| Називний відмінок | Давальний відмінок |
|---|---|
| я | мені́ |
| ти | тобі́ |
| він | йому́ |
| вона́ | їй |
| ми | нам |
| ви | вам |
| вони́ | їм |

A side table shows how the numeral before "years" depends on the last digit(s) of the number. (This is the standard Ukrainian numeral-agreement pattern: forms ending in 1 → singular nominative-like form; forms ending 2–4 → the "few" form; everything else, plus 11–14, → the genitive-plural form.)

| Last digit(s) of the number | Word for "year(s)" |
|---|---|
| 1, 21, 31, 41… | рік |
| 2, 3, 4, 22, 23, 24, 32, 33, 34… | ро́ки |
| 5–20, 25–30, 35, 36, 37, 38, 39, 40… | ро́ків |

### 0.9 Країни: родовий відмінок (Countries: Genitive Case)

Model question: *Звідки Ви/ти?* → *Я з + країна (родовий відмінок).* ("Where are you from? → I'm from + country," genitive case after **з**.)

| Ending pattern | Nominative | Genitive |
|---|---|---|
| -а → -и | Украї́на | Украї́ни |
| -ща → -щі | По́льща | По́льщі |
| -ія → -ії | Іспа́нія | Іспа́нії |
| Ø → -у | Іра́н | Іра́ну |
| -й → -ю | Кита́й | Кита́ю |

### Рід іменника (Gender of Noun)

Ukrainian nouns fall into three genders — **чоловічий рід** (masculine), **жіночий рід** (feminine), and **середній рід** (neuter) — and gender is normally predictable from the ending:

| Masculine | Feminine | Neuter |
|---|---|---|
| **-Ø** (рік, вік, худо́жник, музе́й) | **-а** (ручка, студе́нтка), **-я** (ву́лиці, професія) | **-о** (вікно), **-е** (прі́звище) |
| + тато, дядько, + Мико́ла, Сашко́, + судя́ (male occupations/names ending in -о/-а are still masculine) | + 2-я (два однакові приголосні перед -я: завда́ння, коха́ння, життя; but стаття is feminine) | + -ня (ім'я, здоров'я, подві́р'я — but сім'я is feminine) |

Also covered: + ра́дість, ні́жність, сіль, націonáльність (feminine abstract/collective nouns ending in a soft consonant) belong to the feminine group above.

**Numeral ОДИН (Numeral "one")** agrees with the noun's gender: ОДИН + masculine noun, ОДНА + feminine noun, ОДНЕ + neuter noun.

## 1. Іменники, прикметники, дієслово БУТИ (Nouns, Adjectives, the Verb БУТИ)

### 1.1 Особові займенники: родовий відмінок (Personal Pronouns: Genitive Case)

Model question: *У Вас/тебе є сім'я?* → *Так, у мене є сім'я.* ("Do you have a family? → Yes, I have a family.")

To express **possession of something**, Ukrainian uses the construction: **у + personal pronoun (genitive case) + є + person/object (nominative case)**.

| Називний відмінок | Родовий відмінок | Знахідний відмінок |
|---|---|---|
| я | ме́не | = ме́не |
| ти | те́бе | = те́бе |
| він | його́ | = його́ |
| вона́ | її́ | = її́ |
| ми | нас | = нас |
| ви | вас | = вас |
| вони́ | їх | = їх |

(Genitive and accusative happen to share these forms for personal pronouns.)

The guide also drills the alternate **"closed form"** genitive series used after **у** in possession constructions, alongside **є** ("[there] is") and everyday nouns (ма́ма, та́то, брат) to build *У Вас/тебе є ручка? → Так, є. / Ні, нема́є/нема.* ("Do you have a pen? → Yes, [I do]. / No, [I don't].")

| Називний відмінок ("закрита форма") | | Називний відмінок (example) |
|---|---|---|
| я → у ме́не | | ма́ма, та́то, брат |
| ти → у те́бе | | |
| він → у ньо́го | Є | |
| вона́ → у не́ї | | |
| ми → у нас | | |
| ви → у вас | | |
| вони́ → у них | | |

### 1.2 Присвійні займенники (Possessive Pronouns)

The gender and number of a possessive pronoun depends on the gender and number of the **noun that follows it** (not the possessor): *мій брат* (m.), *твоя́ сестра́* (f.).

| Особовий займенник | Чоловічий рід | Жіночий рід | Середній рід | Множина |
|---|---|---|---|---|
| я | мій | моя́ | моє́ | мої́ |
| ти | твій | твоя́ | твоє́ | твої́ |
| він | його́ | його́ | його́ | його́ |
| вона́ | її́ | її́ | її́ | її́ |
| воно́ | його́ | його́ | його́ | його́ |
| ми | наш | на́ша | на́ше | на́ші |
| ви | ваш | ва́ша | ва́ше | ва́ші |
| вони́ | їхній | їхня | їхнє | їхні |
| ?(ХТО? ЩО?) | Чий? | Чия́? | Чиє́? | Чиї? |

### 1.4 Множина іменників (Plural Form of Nouns)

Most Ukrainian nouns have two numbers: **1 – однина́** (singular) vs. **2, 3, 4… – множина́** (plural). Plural formation depends on gender and the final consonant/vowel of the stem:

| Gender | Singular ending | Plural ending | Examples |
|---|---|---|---|
| Masculine | -Ø | -и / -і (-ж,-ч,-ш,-щ → -і; -ар/-яр → -і; -й → -ї) | брат→брати́, учи́тель→учителі́, ніж→ножі́, шко́ляр→шко́лярі, трамва́й→трамва́ї |
| Masculine | -ар/-яр (лі́кар, шко́ляр) | -і / -ярі | лі́кар→лі́карі, шко́ляр→шко́лярі |
| Feminine | -а | -и (after hard consonant) / -і (after ж,ч,ш,щ) | подру́га→подру́ги, пло́ща→пло́щі |
| Feminine | -я | -і / -ї (in -ня, -я + 2 consonants) | ба́бус­я→ба́бусі, сім'я́→сі́м'ї, профе́сія→профе́сії |
| Neuter | -о | -а | лі́жко→лі́жка |
| Neuter | -е | -а | я́йце→я́йця́ |
| Neuter | -я (2 + я) | -я | завда́ння→завда́ння (unchanged) |

**Rules called out with worked examples:**

1. Masculine nouns ending in **-і + consonant** change that **-і- → -о-/-е-** in the plural: сті́л → столи́, ніч → но́чі, папі́р → папе́ри.
2. Masculine nouns ending in **-ець/-ень** lose the **-е-** when the plural ending is added: украї́нець → украї́нці, день → дні.
3. Masculine nouns with the suffix **-ок** lose the **-о-**: буди́нок → буди́нки, гурто́житок → гурто́житки.
4. The letter **Л** is special: if a change happens right before it, a soft sign **-ь-** is inserted: ко́лір → ко́льори, стіле́ць → стільці́.

**Irregular plurals** (memorize as a set):

| Одни́на | Множина́ |
|---|---|
| ма́ти | матері́ |
| ім'я́ | імена́ |
| друг | друзі́ |
| дівчи́на | дівча́та |
| дити́на | ді́ти |
| лю́дина | лю́ди |
| о́ко | о́чі |
| кві́тка | кві́ти |
| ку́рка | ку́ри |

> [!note] These irregular plurals are never used with a number. After the numbers 2, 3, and 4, nouns take their normal plural form instead: *Ось на́ші дівча́та, але́ Тут чоти́ри дівчи́ни.* ("Here are our girls, but: Here are four girls.") *У не́ї гарні о́чі, але́ У нього два ока.* ("She has beautiful eyes, but: He has two eyes.") *Це й кві́ти, але́ Тут три кві́тки.* ("These are flowers, but: Here are three flowers.")

Stress can also shift in the plural of some nouns: син – сини́, жі́нка – жінки́, лі́жко – лі́жка. However, feminine and neuter nouns after the numbers 2, 3, and 4 do **not** shift stress: ві́кно – два вікна́ (window/two windows — stress stays on the same syllable as the plural, unlike the numberless plural). *сестра́ – се́стри, алé дві сестри́.*

**Nouns of foreign origin** ending in -е(-є), -і(-і), -а(-я), -о, -у, -ю do not change form in the plural or in any oblique case. Nouns denoting objects are usually neuter by default; nouns denoting people take masculine or feminine gender based on the person's sex: *кіно = кіно (с.р.), таксі = таксі (с.р.), меню = меню (с.р.)* — "cinema," "taxi," "menu" are all treated as neuter.

**Numeral ДВА (Numeral "two")**: ДВА + masculine noun (сто́ли, підру́чники), ДВІ + feminine noun (ша́фи, кни́жки), ДВА + neuter noun (вікна́, лі́жка).

### 1.7 Рід та число прикметника (Adjective: Gender and Number)

An adjective agrees in gender and number with the noun it describes.

| Masculine | Feminine | Neuter | Plural |
|---|---|---|---|
| -ий/-ій (зеле́ний/си́ній підру́чник) | -а/-я (зеле́на/си́ня кни́жка) | -е/-є (зеле́не/си́нє мо́ре) | -і (зеле́ні/сині па́рти) |

## 2. Місцевий відмінок (Locative Case)

### 2.2 Місцевий відмінок іменника (Locative case of Noun)

The **locative case** is used to say *where* a thing or person is. It always appears with the prepositions **в/у** or **на**.

- **В/У** — "inside" (в/у готе́лі, в/у музе́ї — in a hotel, in a museum)
- **НА** — "on the surface, on top" (на пове́рхні, наго́рі)

**Singular:**

| Gender | Nominative | Locative |
|---|---|---|
| Masculine | університе́т, готе́ль, музе́й | в університе́ті, у/в готе́лі, у/в музе́ї |
| Feminine | це́рква, ву́лиця, ста́нція, галере́я | у/в це́ркві, на ву́лиці, на ста́нції, у/в галере́ї |
| Neuter | вікно́, мо́ре | на вікні́, у/в мо́рі |

**Plural:**

| Gender | Nominative (plural) | Locative (plural) |
|---|---|---|
| Masculine | університе́ти, готе́лі, музе́ї | в університе́тах, у/в готе́лях, у/в музе́ях |
| Feminine | це́ркви, ву́лиці, ста́нції, галере́ї | у/в це́рквах, на ву́лицях, на ста́нціях, у/в галере́ях |
| Neuter | ві́кна, моря́ | на ві́кнах, на моря́х |

**Watch out!**

1. Masculine and neuter nouns ending in **-ок, -ак, -ик,** or **-ко** take the ending **-у** in the locative singular (not the usual -і): буди́нок → у буди́нку, літа́к → у літа́ку, слóвник → у словнику́, лíжко → у лі́жку. (Exception noted: the suffix **-ок** loses its **-о-** first, then adds -у.)
2. Short one-syllable masculine nouns often also take **-у**: парк → у па́рку, банк → у ба́нку, порт → у по́рту.
3. In all genders, the locative singular can trigger a **-і- → -о-** stem change before the ending: мíст → на мос­ту́/мо́сті.
4. Nouns ending in a stem consonant followed by **-к-** trigger a **к → ц** shift plus **-і**: Аме́рика → в Аме́риці, уро́к → на уро́ці, о́ко → в о́ці.
5. Words ending in **-і + consonant** shift **-і- → -о-**: рік → у ро́ці; and stems ending **-г → -з-** before **-і**: Еди́нбург → в Еди́нбурзі, доро́га → на доро́зі.

**Plural** locative forms follow their own pattern by gender and stem-final consonant (e.g. університе́ти → в університе́тах/готе́лях/музе́ях; це́ркви → у це́рквах; ві́кна → на ві́кнах).

**Choosing В/У vs. НА** is largely lexical (memorize per-noun/situation) rather than fully rule-governed:

| Category | В/У (inside) | НА (surface / event) |
|---|---|---|
| Меsце (place) | усере́дині (у мо́рі, в столі́, в лі́жку) | на пове́рхні (на мо́рі, на столі́, на лі́жку) |
| По́дія (event) | — | подія (у теа́трі, в університе́ті, в галере́ї / на ви́ставі, на ле́кції) |
| Закри́тий про́стір (enclosed space) | у музе́ї, у шко́лі, у рестора́ні | — |
| Відкри́тий про́стір (open space) | — | на стадіо́ні, на вокза́лі, на заво́ді, на зупи́нці, на по́шті |
| Контине́нти (continents) | в Аме́риці, у/в Австра́лії, у/в Євро́пі | — |
| Острови́ і озе́ра, моря́ (islands, lakes, seas) | — | на Кара́ібах, на Гава́йях, на Сві́тязі, на Чо́рному мо́рі |
| Краї́ни, міста́, се́ла (countries, cities, villages) | в Украї́ні, у Вене́ції, у Морі́нцях | — |
| Сто́рони сві́ту (cardinal directions) | — | на пі́вночі, на пі́вдні, на за́ході, на схо́ді |
| Ву́лиці, пло́щі (streets, squares) | — | на ву́лиці Шевче́нка, на пло́щі Фра́нка |
| Буди́нки (buildings) | у буди́нку, у ра́туші, у це́ркві | — |
| Навча́льні заклади (educational institutions) | в університе́ті, в інститу́ті, у ко́леджі | — |
| Факульте́ти, ку́рси (faculties, courses) | — | на факульте́ті, на ку́рсі |

Prepositional details also given: В (у) is used (1) between two vowels, (2) before a consonant after a vowel, (3) after a vowel before a consonant (except в, ф, хв, св, тв, льв). У is used (1) between two consonants, (2) at the start of a sentence before a consonant, (3) before consonants в, ф, хв, св, тв, льв.

### 2.4 ЧАС: дієслово БУТИ (Tense: the verb БУТИ, "to be")

Ukrainian verbs have three tenses: **тепе́рішній час** (present, "today"), **мину́лий час** (past, "yesterday"), and **майбу́тній час** (future, "tomorrow"). In the present and future tenses verbs change by person and number; in the past tense they change by gender and number.

In the present tense, **БУТИ** ("to be") is normally not used — it is only kept in constructions about possession (**У мене є...**, **У тебе є...**). БУТИ's present-tense forms are all **є** (shown as the omitted default for most persons), while the future forms conjugate normally:

| | Тепе́рішній час | Майбу́тній час |
|---|---|---|
| я | є / --- | бу́ду |
| ти | є / --- | бу́деш |
| він | є / --- | бу́де |
| вона́ | є / --- | бу́де |
| воно́ | є / --- | бу́де |
| ми | є / --- | бу́демо |
| ви | є / --- | бу́дете |
| вони́ | є / --- | бу́дуть |

In the past tense, БУТИ changes by gender/number:

| Gender/number | Мину́лий час |
|---|---|
| Чолові́чий рід | був |
| Жіно́чий рід | булá |
| Сере́дній рід | булó |
| Множина́ | бу́ли |

|---|---|---|---|
| бажáти | I | нести́ | I |

## 3. Дієслово (The Verb)

### 3.1 Дієслово: інфінітив та дієвідміни (Verb: Infinitive and Conjugations)

A verb denotes an action. Its starting/dictionary form is the **infinitive** — the form you find in dictionaries. In Ukrainian, infinitives always end in **-ти**.

Verbs fall into two conjugation classes, **I (перша) дієвідміна** and **II (друга) дієвідміна**. Verbs whose stem ends in **-и-/-і-** right before the final **-ти** in the infinitive (plus **спа́ти, бíгти**) usually belong to conjugation **II**: *бачити, сидіти*. Most other verbs belong to conjugation **I** — this is the larger group. A handful of verbs belong to neither class and have their own irregular forms, e.g. **бу́ти, ї́сти, да́ти**, and verbs ending in **-вісти**.

### 3.2 Дієслово: теперішній час (Verb: Present Tense)

In the present tense, verbs change by person and number. To form the present tense:

1. Determine the verb's conjugation class: e.g. *чита́ти* – I, *вчи́ти* – II.
2. Drop the infinitive suffix **-ти** (and, for conjugation II, the vowel immediately before it).
3. Identify the **stem** and its final letter: *чита-* / *вч-*.
4. Find the matching ending in the table below and add it to the stem.

**Conjugation I** stem-final-letter → ending, by person:

| | Consonant-final stem | Vowel-final stem (А,О,У,Е,И,Я,Ю,Є,Ї) |
|---|---|---|
| я | -у | -ю |
| ти | -еш | -єш |
| він/вона | -е | -є |
| ми | -емо | -ємо |
| ви | -ете | -єте |
| вони | -уть | -ють |

**Conjugation II** stem-final-letter → ending, by person:

| | Consonant-final stem (except ж,ч,ш,щ) | ж,ч,ш,щ-final stem | Vowel-final stem (А,О,У,Е,И,Я,Ю,Є,Ї) |
|---|---|---|---|
| я | -у | -у | -ю |
| ти | -иш | -иш | -їш |
| він/вона | -ить | -ить | -їть |
| ми | -имо | -имо | -їмо |
| ви | -ите | -ите | -їте |
| вони | -ать | -ать | -ять |

**Reflexive verbs** — those with **-ся(-сь)** after **-ти** in the infinitive — add the reflexive particle **-ся(-сь)** to every present-tense form, after the ordinary personal ending: *я вмива́юся, ти вмива́єшся, він/вона́ вмива́єтьcя→вмива́єтьcя* (Note: in the third person singular/plural, before **-ся(-сь)** the personal ending's final **-ть** becomes **-ться**.) Most reflexive verbs have a non-reflexive counterpart (*ди́витися – ди́вити*, though a small number, like *дивитися, усміха́тися*, are used only reflexively).

### 4.1 Дієслово: чергування приголосних у теперішньому часі (Verb: Consonant Interchanges in Present Tense)

In some verbs, forming the present tense from the infinitive triggers a **consonant alternation**.

In **conjugation I** verbs, the alternation occurs in **all** person forms: с→ш (писа́ти – пишу́, пи́шеш...), г→ж (могти́ – мо́жу, мо́жеш...), т→ч (хоті́ти – хо́чу, хо́чеш...), з→ж (каза́ти – кажу́, ка́жеш...).

In **conjugation II** verbs, the alternation occurs **only in the first person singular (Я)**: д→дж (ненави́діти – ненави́джу, ненави́диш...), с→ш (проси́ти – прошу́, про́сиш...), т→ч (лете́ти – лечу́, лети́ш...).

### 4.2 Дієслово: минулий час (Verb: Past Tense)

Past-tense verbs change by gender and number. Formation: take the infinitive stem and add **-в** (masculine), **-ла** (feminine), **-ло** (neuter), or **-ли** (plural) — e.g. *чита́ти → чита́+в/ла/ло/ли*.

Reflexive verbs follow the same pattern but insert **-ся** after the gender/number suffix: *ми́тися → ми+в+ся, ми+ла+ся, ми+ло+ся, ми+ли+ся.*

Some verbs have irregular past-tense forms (memorize as sets):

| Infinitive | Чол. рід | Жін. рід | Сер. рід | Множина́ |
|---|---|---|---|---|
| ї́сти | їв | ї́ла | ї́ло | ї́ли |
| іти́ | ішо́в | ішла́ | ішло́ | ішли́ |
| знайти́ | знайшо́в | знайшла́ | знайшло́ | знайшли́ |
| могти́ | міг | могла́ | могло́ | могли́ |
| допомогти́ | допомі́г | допомогла́ | допомогло́ | допомогли́ |

### 4.4 Дієслово: майбутній час недоконаного виду (Verb: Future Imperfective Tense)

The compound future-imperfective form is built by combining the future form of **БУТИ** (which conjugates by person/number) with the **imperfective infinitive** of the main verb: **БУТИ (future tense) + infinitive**, e.g. я бу́ду чита́ти, ти бу́деш чита́ти, etc.

### 4.7 Кличний відмінок (Vocative case)

The **vocative case** is used to address a person or thing directly. Neuter nouns, and all nouns in the plural, take the same endings as in the nominative case (of the plural).

| Gender | Nominative | Ending | Кличний відмінок |
|---|---|---|---|
| Чолові́чий рід | брат | -е | бра́те |
| Чолові́чий рід | бра́тик, Ма́рко + та́то | -ику/-ко/-ко | бра́тику, Ма́рку, та́ту |
| Чолові́чий рід | син, дід | -у | си́ну, ді́ду |
| Чолові́чий рід | ді́дусь, Андрі́й, лі́кар (alé хло́пець) | -ю/-й/-ар | ді́дусю, Андрі́ю, лі́карю (alé хло́пче) |
| Жіно́чий рід | ма́ма | -о | ма́мо |
| Жіно́чий рід | Ната́ля | -ю | Ната́лю |
| Жіно́чий рід | Софі́я | -іе | Софіє́ |
| Сере́дній рід | коха́ння | (= Nom.) | коха́ння |
| Множина́ | бра́ти, се́стри / па́ні | (= Nom. pl.) | бра́ти сестри́ / па́ні/пано́ве |

> [!tip] When addressing an audience, the standard formula is **Шано́вні па́ні та пано́ве!** ("Distinguished ladies and gentlemen!")

### 5.2 Знахідний відмінок (неістоти) (Accusative Case of Inanimate Nouns)

The **accusative case** marks the object of an action. Inanimate nouns change form as shown below (mostly identical to the nominative except for feminine -а/-я → -у/-ю):

| Gender | Nominative | Знахідний відмінок |
|---|---|---|
| Чолові́чий рід | снідáнок, чай, йо́гурт, сік | = Nom. |
| Жіно́чий рід | ка́ва, пі́ца, ку́рка, я́ечня | ка́ву, пі́цу, ку́рку, я́ечню (-а→-у, -я→-ю) |
| Сере́дній рід | я́йце, молоко́, желе́, моро́зиво | = Nom. |
| Множина́ | бутербро́ди, млинці́ | = Nom. pl. |

> [!note] Feminine nouns that do **not** end in a vowel in the nominative singular (i.e. end in a consonant) also do not change in the accusative: *Це сіль (Н.в.). Ви ма́єте сіль (З.в.)?* ("This is salt. Do you have [any] salt?")

**Accusative case of the adjective**: the same feminine -а→-у / -я→-ю shift applies to adjectives modifying inanimate nouns; masculine and neuter adjectives are unchanged from the nominative.

| Gender | Nominative | Зна́чідний відмінок |
|---|---|---|
| Чолові́чий рід | солóдкий пе́рсик | = Nom. |
| Жіно́чий рід | солóдка цуке́рка, си́ня цибу́ля | солóдку цуке́рку, си́ню цибу́лю |
| Сере́дній рід | бі́ле молоко́ | = Nom. |
| Множина́ | смачні́ фру́кти | = Nom. pl. |

**Use of the accusative case**: it follows verbs and phrases like *люби́ти, ненави́діти, готувáти, хоті́ти, купувáти, замовляти, ма́ти, ї́сти, пи́ти, вчи́ти, зна́ти, розумі́ти, ба́чити, чу́ти, співáти, читáти, писáти* ("to love, hate, prepare, want, buy, order, have, eat, drink, learn, know, understand, see, hear, sing, read, write") and *Дай/Дайте, будь ла́ска...* ("Give me, please..."), and after the preposition **про** ("about"): *Я люблю́ читáти про Украї́ну.* On the other hand, **на** takes the accusative to express direction — *(напрям)* Ми ї́демо на мо́ре — or a time period — *(час)* Ми ї́демо на мо́ре на ти́ждень — while **у/в** takes the accusative for direction (Студе́нти йдуть в Аме́рику) or a stretch of non-working time (У неді́лю ми не працю́ємо).

**Genitive case of adjectives:**

| Gender | Nominative | Родо́вий відмінок |
|---|---|---|
| Чолові́чий рід | солóдкий пе́рсик, сусі́дній сті́лець | солóдкого пе́рсика, сусі́днього стільця́ |
| Жіно́чий рід | солóдка цуке́рка, си́ня цибу́ля | солóдкої цуке́рки, си́ньої цибу́лі |
| Сере́дній рід | бі́ле молоко́, сусі́днє по́ле | бі́лого молока́, сусі́днього по́ля |
| Множина́ | солóдкі пе́рсики, солóдкі цуке́рки, сві́жі я́йця | солóдких пе́рсиків, солóдких цуке́рок, сві́жих я́єць |

**Rules for masculine nouns ending in -і + consonant** (→ -о-/-е-): сті́л → столá.
**Nouns ending -ець/-ень** lose -е-: украї́нець → украї́нця, день → дня.
**Nouns with the -ок suffix** lose -о-: буди́нок → буди́нку, гурто́житок → гурто́житку.
**The letter Л** again inserts a soft sign when a change occurs before it: коло́р → ко́льору, стіле́ць → стільця́.

**Genitive plural of feminine/neuter nouns**: when the loss of the final stem vowel would create an impossible consonant cluster, an inserted **-о-** or **-е-** vowel appears between the last two consonants, and any stem **-о-** alternates with **-і-**: ку́рка → куро́к, це́рква → церко́в, лі́жко → лі́жок; ви́шні → вишень, я́йця (й+е→ець) → яєць, крі́сла → крі́сел; also -о- + consonant → -і- + consonant: робо́та → робіт, коро́ва → коро́в, сло́во → слів.

Feminine nouns whose nominative singular ends in a consonant take **-ей** in the genitive plural: ніч → ноче́й, річ → рече́й — same for a set of common irregular plurals: лю́ди → люде́й, ді́ти → діте́й, гóсті → гостей, две́рі → двере́й, гро́ші → гроше́й, óчі → оче́й, сім'ї́ → сіме́й, ко́ні → коне́й, ми́ші → миш́ей.

**Masculine nouns' genitive singular ending depends on meaning** — Ø, -а/-я vs. Ø, -у/-ю:

| Category | -а/-я | Category | -у/-ю |
|---|---|---|---|
| 1. Concrete objects | сті́л→столá, комп'ю́тер→комп'ю́тера | 1. Abstract concepts/events | сон→сну, екза́мен→екза́мену |
| 2. Countable substances | помідо́р→помідо́ра | 2. Uncountable substances | сир→си́ру, цу́кор→цу́кру |
| 3. People | чолові́к→чолові́ка, Андрі́й→Андрі́я | 3. Buildings, institutions | буди́нок→буди́нку, університе́т→університе́ту |
| 4. Individual items/people | учень→у́чня, музика́нт→музика́нта | 4. Collective concepts | клас→кла́су, парк→па́рку |
| 5. Cities | Ки́їв→Ки́єва, Льві́в→Льво́ва | 5. Countries, regions | Єги́пет→Єги́пту, Крим→Кри́му |
| 6. Nature objects | мі́сяць→Мі́сяця | 6. Nature phenomena | дощ→до́щу, сніг→сні́гу |

**When to use the genitive case:** (1) possession — сім'я́ Оле́ни, студе́нти університе́ту; (2) ownership — У ме́не (Р.в.) є сестрá; (3) in negated constructions — Петро́ не мáє грошéй; У магази́ні неме́ає цу́кру; (4) after the preposition **без** ("without") — У Вас є салáт без майонéзу?; (5) after quantity words like **(не)бага́то, тро́хи, (де)кі́лька, ма́ло, скі́льки** — Ми купи́ли бага́то овочі́в; (6) after numerals **5 to 20**, plus **30, 40, 50, 60...** — У ме́не є 5 сесте́р; (7) after words for **volume/containers** — Дáйте, будь лáска, пля́шку молокá.

| Жіно́чий рід | каре́та, цибу́ля, коле́кція | каре́тою, цибу́лею, коле́кцією |
| Сере́дній рід | молокó, я́йце, варе́ння | молокóм, я́йцем, варе́нням |

**Plural:**

| Gender | Nominative (plural) | Ору́дний відмінок (plural) |
|---|---|---|

| Жіно́чий рід | оліви́ці, полуни́ці | оліви́цями, полуни́цями |
| Сере́дній рід | я́блука, я́йця, побача́ння | я́блуками, я́йцями, побача́ннями |

Stem-change rules mirror those already seen: -і- + consonant → -о-/-е- (сті́л → столóм); nouns ending -ець/-ень lose -е- (украї́нець → украї́нцем); nouns with the -ок suffix lose -о- (буди́нок → буди́нком); the letter Л again inserts -ь- when a change precedes it (кóлір → кóльором).

Feminine nouns ending in a consonant with an unchanged stem take **-ю** in the instrumental, and the final consonant doubles (ніч → ні́ччю, сіль → сі́ллю, ві́дповідь → ві́дповіддю) — unless the stem already ends in two consonants (крoв → кро́в'ю, любо́в → любо́в'ю) or ends -б,-п,-в,-м,-ф (labial) or -р, where an apostrophe appears before the ending instead of doubling (кров → кро́в'ю).

**Irregular instrumental plurals**: ді́ти → ді́тьми, лю́ди → людьми́, гро́ші → грі́шьми, кóні → кі́ньми.

| Називний відмінок | Ору́дний відмінок |
|---|---|
| я | мно́ю |
| ти | тобóю |
| він | ним |
| вона́ | не́ю |
| ми | нáми |
| ви | вáми |
| вони́ | ни́ми |

**Use of the instrumental case**: (1) to express the instrument of an action — писáти ру́чкою, малювáти олі́вцем; (2) after the preposition **з** meaning "together/with" — кáва з цу́кром, Оле́на з сім'єю́, Марко́ з Дзвінко́ю; (3) after **займáтися, захо́плюватися, ціка́витися** ("to be engaged in / be into / be interested in") when talking about hobbies — займáтися спóртом, ціка́витися му́зикою, захо́плюватися живопи́сом; (4) after **БУТИ** (only in the past and future tenses) and after **стáти, працювáти** when talking about profession — Моя́ сестрá — вчи́телька (present, nominative), Моя́ бáбуся булá вчи́телькою (past, instrumental), Моя́ до́чка бу́де вчи́телькою (future, instrumental); Мій син стáне футболі́стом; Мій брат працю́є перекладаче́м.
5) after certain verbs used with the preposition **з** meaning "together" — розмовля́ти/говори́ти з, одружи́тися з, познайо́митися з, зустріча́тися/зустрі́тися з, цілувáтися з, грáти з; 6) in exclamatory phrases with **з** — Із задово́ленням! ("With pleasure!"), З рáдістю! ("Gladly!").

> [!note] Attention! The preposition **з** has several phonetic variants for smoothness of speech (see the fuller version of this rule under §4.4 "З / ІЗ / ЗІ" in [[yabluko-l2-grammar-guide-en|the Level 2 guide]], which spells out the same rule in prose): **з** is used between two vowels, before a vowel after a consonant, or after a vowel before a consonant (except в, ф, льв, св, тв, хв); **із** is used between two consonants, or before с/ш regardless of what precedes; **зі** is used before a consonant cluster that starts with з-/с-/ц-/ч-/ш-/щ-, and with the fixed forms **зі мно́ю**, **зі Льво́вом**.

### 6.6 Фраза Я Б ХОТІВ.../Я Б ХОТІЛА... (The phrase "I would like...")

*Я б хотів / Я б хотіла...* is a more polite way of making a request than *Я хочу* ("I want"). The words *хотів/хотіла* here are not actual past-tense forms and cannot be used to mean past time — grammatically, this is the **conditional mood**, formed with the past-tense form of the verb plus the particle **б/би** in a pre- or post-positive position.

The variant **б** is used when the preceding word ends in a vowel, and **би** when the preceding word ends in a consonant:

| Preceding word ends in... | Particle | Example |
|---|---|---|
| vowel | б | Вона́ б хоті́ла... |
| consonant | би | Він би хоті́в... |

### 8.2 Порядкові числівники: називний відмінок, місцевий відмінок (Ordinal Numerals: Nominative and Locative)

Ordinal numerals indicate the **order** of persons or objects when counting, and answer **Котри́й?/Котрá?/Котре́?/Які́?** ("which one, in order?") or **Яки́й?/Яка́?/Яке́?/Які́?** ("what/which"). Ordinal numerals decline by number, gender, and case just like adjectives, and agree with the noun they modify: *пе́рший урóк, пе́рша ле́кція, пе́рше зaня́ття, пе́рші словá* ("first lesson," m./f./n./pl.").

| # | Чолові́чий рід | Жіно́чий рід | Сере́дній рід | Множина́ |
|---|---|---|---|---|
| 1st | пе́рший | пе́рша | пе́рше | пе́рші |
| 2nd | дру́гий | дру́га | дру́ге | дру́гі |
| 3rd | тре́тій | тре́тя | тре́тє | тре́ті |
| 4th | четве́ртий | четве́рта | четве́рте | четве́рті |
| 5th | п'я́тий | п'я́та | п'я́те | п'я́ті |
| 6th | шо́стий | шо́ста | шо́сте | шо́сті |
| 7th | сьо́мий | сьо́ма | сьо́ме | сьо́мі |
| 8th | во́сьмий | во́сьма | во́сьме | во́сьмі |
| 9th | дев'я́тий | дев'я́та | дев'я́те | дев'я́ті |
| 10th | деся́тий | деся́та | деся́те | деся́ті |

The same set of ordinals in the **locative case** (used with a preceding number to say "at what place," e.g. на пе́ршому/тре́тьому...):

| # | Чолові́чий рід | Жіно́чий рід | Сере́дній рід | Множина́ |
|---|---|---|---|---|
| 1st/3rd | на пе́ршому/тре́тьому | на пе́ршій/тре́тій | на пе́ршому/тре́тьому | на пе́рших/тре́тіх |

> [!note] In compound ordinal numbers, only the **last element** takes the ordinal form: *двáдцять пе́рше число́* ("the twenty-first [day of the month]"), *сóрок дев'я́тий повéрх* ("the forty-ninth floor").

Ordinal numerals are used very often — for page numbers, exercises, lessons and chapters, transport routes, buildings/apartments, floors, auditoriums, rows, seats, classes, courses, and dates. But when a number follows the noun rather than precedes it, **cardinal** numerals are used instead: *сто́рінок — три́дцять чоти́ри вправ; дванáдцята сто́рінка, alé сто́рінка двáнадцять* ("page twelve" vs. "page number twelve").

**Locative case of ordinal numerals** is used to indicate a place (Де?) — на пе́ршому пове́рсі, у трина́дцятій аудито́рії — and, without a preceding number, to indicate a year (Коли́?) — у дві ти́сячі п'ятна́дцятому ро́ці, в (одна) ти́сяча дев'ятсо́т дев'яно́сто пе́ршому ро́ці.

### 8.4 Дати: родовий відмінок порядкових числівників (Dates: Genitive Case of Ordinal Numerals)

When answering **Коли?**, if the day, month, and year are all given, they all take the **genitive case**: *Ко́лі Ви народи́лися? — Я народи́вся пе́ршого сі́чня ти́сяча дев'ятсо́т вісімдеся́т тре́тього ро́ку.*

Ordinal numerals in the genitive case decline exactly like adjectives:

| Nominative | Родо́вий відмінок |
|---|---|
| пе́рший/тре́тій (m.) | пе́ршого/тре́тього |
| пе́рша/тре́тя (f.) | пе́ршої/тре́тьої |
| пе́рше/тре́тє (n.) | пе́ршого/тре́тього |
| пе́рші/тре́ті (pl.) | пе́рших/тре́тіх |

### 8.6 Години: місцевий відмінок порядкових числівників (Time: Locative Case of Ordinal Numerals)

Time-of-day question: **Ко́тра годи́на?** ("What time is it?") → **П'я́та (годи́на)** ("Five [o'clock]" — feminine ordinal agreeing with the implied feminine noun годи́на).

When stating minutes as well, the **hour** uses the ordinal numeral (feminine), but the **minutes** use the cardinal numeral:

| | Годи́ни (hours) | Хвили́ни (minutes) |
|---|---|---|
| Form | Поря́дковий числі́вник (ж.р.) | Кі́лькісний числі́вник |
| Example | п'я́та (годи́на) | со́рок (хвили́н) |

When answering **Коли́?/О ко́трій годи́ні?** ("At what time?"), the hour takes the **locative case with the preposition о/об**, while the minutes stay in the **nominative case with a cardinal numeral**:

| | Годи́ни (hours) | Хвили́ни (minutes) |
|---|---|---|
| Form | Поря́дковий числі́вник (ж.р.) у місце́вому відмі́нку з прийме́нником о/об | Кі́лькісний числі́вник у назви́ному відмі́нку |
| Example | о п'я́тій (годи́ні) | об одина́дцятій (годи́ні) |

## 9. Дієслова руху (Verbs of Motion)

### 9.1 Прислівники способу дії (Adverbs of Manner)

Adverbs of manner describe **how** an action (expressed by the verb) takes place. They are typically formed from adjectives: **ПРИКМЕТНИК (-ий/-а/-е) + -о**: швидки́й → шви́дко, гáрний → гáрно. Adjectives with a stem ending in **-ж-,-ч-,-ш-,-щ-,** or **-р-** form their adverb with **-е** instead: гаря́чий → гаря́че, до́брий → до́бре. Adverbs never change form by number, gender, or case.

### 9.2 Дієслова руху: група I (Verbs of Motion, Group I)

Ukrainian verbs of motion fall into two groups depending on their meaning. **Group I** verbs describe motion **at a specific moment** (now/today/at that time) **in a specific direction**, and are often described as unfolding "in process." This group includes іти́, ї́хати, бíгти, летíти, пливти́, нести́, вести́, везти́, лí зти, повзти́. These verbs can occasionally also be used in conversational speech in the present tense to indicate a planned future action: *Зáвтра я їду в університéт.* ("Tomorrow I'm going to university" — planned).

To find out the **direction** of motion, ask **КУДИ?** ("where to?") — answered with **в/на + accusative case** of the noun, or an adverb (додо́му, туди́, сюди́). The construction **до + genitive case** can also express direction: *Я їду в Ки́їв*, or *Я їду до Ки́єва.*

To find out the **place motion originates from**, ask **ЗВІ́ДКИ?** ("from where?") — answered with **з + genitive case** of the noun, or an adverb (зві́дти, зві́дси).

Every Group I verb has a Group II counterpart (see below): *іти́↔ходи́ти, ї́хати↔ї́здити, бíгти↔бíгати, летíти↔літáти, пливтí↔плáвати, нестí↔но́сити, вестí↔во́дити, везтí↔во́зити, лíзти↔лáзити, повзтí↔пóвзати.*

### 9.4 Дієслова руху: група II (Verbs of Motion, Group II)

**Group II** verbs of motion (ходи́ти etc.) describe motion that is: (1) back-and-forth to a place and back (Я ходи́в у музе́й — "I went to the museum [and came back]"); (2) in no fixed direction (Вонá не́рвово хóдить по кímнаті — "She's nervously pacing the room"); or (3) repeated (за́вжди, зазвича́й, чáсто, і́ноді/і́нколи, рі́дко, ніко́ли, щодня́/кóжного дня — "always, usually, often, sometimes, rarely, never, every day"): *Я за́вжди їжджу в університéт автóбусом.*

Each Group I verb has exactly one Group II counterpart.

**Наказовий спосіб дієслова (Imperative Mood of the Verb)**

To command someone to do something, or ask/urge them to, the imperative mood is used. The imperative has three forms: 2nd person singular and plural, and also 1st person plural.

**Formation of imperative forms:**

1. If the verb stem ends in a **vowel**:

   | | Одни́на | Множина́ |
   |---|---|---|
   | I особа | ----------------- | -йо/-ймо |
   | II особа | -й | -йте |

   *Читáти → читáй, читáймо, читáйте.* *Танцюва́ти → танцю́й, танцю́ймо, танцю́йте.* *Купáтися → купáйся, купáймося, купáйтеся.*

2. If the verb stem ends in a **consonant**, and the stress in the infinitive falls **on the syllable right before -ти**:

   | | Одни́на | Множина́ |
   |---|---|---|
   | I особа | ----------------- | -імо |
   | II особа | -и | -іть |

   *Спáти → спи, спі́мо, спіть.* *Ходи́ти → ходи́, ході́мо, ході́ть.* *Диви́тися → диви́ся, диві́мося, диві́ться.*

3. If the verb stem ends in a **consonant**, and the stress in the infinitive falls on a syllable that is **not** adjacent to -ти:

   | | Одни́на | Множина́ |
   |---|---|---|
   | I особа | ----------------- | -мо |
   | II особа | -Ø | -те |

   *Пробáчити → пробáч, пробáчмо, пробáчте.* *Ві́рити → ві́р, ві́рмо, ві́рте.*

4. If the stem ends in **-т, -д, -з, -с, -ц, -л,** or **-н**, a soft sign **-ь-** is used before the ending instead:

   | | Одни́на | Множина́ |
   |---|---|---|
   | I особа | ----------------- | -ьмо |
   | II особа | -ь | -ьте |

   *Приходи́ти → прихóдь, прихóдьмо, прихóдьте.*

Irregular imperatives: **бу́ти** → будь, бу́дьмо, бу́дьте; **ї́сти** → їж, ї́жмо, ї́жте; **дава́ти** → дава́й, дава́ймо, дава́йте; **ітí/ї́хати** → іди́, ідíмо, ідíть; **ля́гти** → ляж, ля́жмо, ля́жте; **сі́сти** → сядь, ся́дьмо, ся́дьте.

When the command, request, or wish concerns a **third person** (singular or plural), the particle **хай (нехай)** is placed before the verb in its present tense form: *Хай він пи́ше. Неха́й вони́ пи́шуть.*

### 9.6 Дієслова ПІТИ/ПРИЙТИ та ПОЇХАТИ/ПРИЇХАТИ (Verbs of motion)

Motion verbs **іти/їхати** with the prefix **по-** (**піти, поїхати**) denote an action that moves **away** from the speaker's current location, expressing departure/leaving the previous location: past tense — *пішов/пішла, поїхав/поїхала* means "was there but isn't now"; future tense — *піду/підеш..., поїду/поїдеш...* means "will be there soon but isn't yet."

Motion verbs with the prefix **при-** (**прийти, приїхати**) denote an action that moves **toward** the destination, expressing arrival at the destination for the actor's next stay there: past tense — *прийшов/прийшла, приїхав/приїхала* means "wasn't there but is now"; future tense — *прийду/прийдеш..., приїду/приїдеш...* means "isn't there yet but will be soon."

> [!note] **ПІТИ/ПРИЙТИ** and **ПОЇХАТИ/ПРИЇХАТИ** are not used in the present tense.

## 10. Ступені порівняння прикметника; дієслово-зв'язка БУТИ (Degrees of Comparison; the Copular Verb БУТИ)

### 10.1 Дієслово-зв'язка БУТИ (Copular Verb "to Be")

We already noted that in the present tense the copular verb БУТИ, meaning "to exist / to be located," is usually omitted, replaced in writing with a dash: *Ки́їв – столи́ця Украї́ни.* ("Kyiv is the capital of Ukraine.")

However, in the **past and future** tenses, БУТИ is **not** omitted, and any noun or adjective following it goes into the **instrumental case**: *Коли́сь він був чемпіо́ном сві́ту.* ("He was once world champion.") *Я ві́рю, що Андрі́й бу́де до́брим чолові́ком для Наталі.* ("I believe Andriy will be a good husband for Natalia.")

БУТИ in the present tense **is** kept in sentences where the accent falls on the *existence* of someone/something (in constructions with У ме́не є..., У те́бе є..., У ньо́го/ньо́ї є... — "I have...," "You have...," "He/she has..."): *У ме́не є ді́ти.* ("I have children.") *У ньо́го є сім'я́.* ("He has a family.")

But if the sentence's emphasis is not on the **existence** of someone/something, but on a **quality or quantity**, then БУТИ (**Є**) is **not** used: *У ме́не двóє дітéй.* ("I have two children" — quantity, no Є.) *У ньо́го вели́ка сім'я́.* ("He has a big family" — quality, no Є.) This is exactly why, in sentences describing physical appearance, БУТИ is never used: *В Наталí гáрне до́вге во́лосся.* ("Natalia has beautiful long hair.") *В Андрі́я вели́кі кáрі óчі.* ("Andriy has big brown eyes.")

### 10.2 Ступені порівняння прикметника: вищий ступінь (Degrees of Comparison of Adjectives: Comparative Degree)

Ukrainian adjectives expressing a quality of a person or thing have **three degrees of comparison**: **звичáйний** (positive/base), **ви́щий** (comparative), and **найви́щий** (superlative). The comparative degree is used when comparing two or more people or objects, to express a greater or lesser degree of a quality.

**Formation of the comparative degree**: the comparative is formed by adding the suffixes **-ш-, -іш-** to the adjective's stem, with some quirks to keep in mind:

1. Adjectives with the suffixes **-к-, -ок-, -ек-** normally form the comparative with **-ш-**, dropping the suffix -к-, -ок-, or -ек-: *широ́кий → ши́рший.*
2. However, a set of adjectives with suffixes **-к-, -ок-, -ек-** instead form the comparative with **-іш-**, in which case those suffixes are **kept**: *стру́нкий → стрункíший.*
3. When forming the comparative with these suffixes, some **consonant alternations** also occur at the boundary: **г+ш=жч** (дороги́й → доро́жчий), **ж+ш=жч** (важки́й → важчий), **з(ь)+ш=жч** (низьки́й → нижчий), **с+ш=щ** (виcо́кий → ви́щий).
4. Sometimes Ukrainian instead uses an **analytical (compound) comparative form**, built with the words **більш** or **менш** before the ordinary (positive-degree) form of the adjective: *відо́мий → більш/менш відо́мий* ("[more/less] famous").
5. Some adjectives form their comparative from an entirely different root (**suppletive forms**): *гáрний/до́брий/хоро́ший → крáщий* ("better"), *пога́ний → гíрший* ("worse"), *вели́кий → бíльший* ("bigger"), *мали́й → ме́нший* ("smaller").

Comparative-degree adjectives change by gender, number, and case just like ordinary adjectives.

### 10.3 Порівняльні конструкції (Patterns of Comparison)

Several constructions exist for comparing people or objects using the comparative degree:

1. **___ , НІЖ + nominative case** — *Наталя ви́ща, ніж Оле́на.* ("Natalia is taller than Olena" — the comma before ніж is always required.)
2. **___ ЗА + accusative case** — *Наталя ви́ща за Оле́ну.*
3. **___ ВІД + genitive case** — *Наталя ви́ща від Оле́ни.*

### 10.4 Ступені порівняння прикметника: найвищий ступінь (Degrees of Comparison of Adjectives: Superlative Degree)

The **superlative degree** expresses the greatest or least degree of a quality among a group. **Formation**: add the prefix **НАЙ-** to the comparative form: *ши́рший → найши́рший.*

To express an even greater intensity of the quality, the particles **ЩО-** or **ЯК-** can be added before the superlative form: *найкрáщий → щонайкрáщий/якнайкрáщий*, *найбíльший → щонайбíльший/якнайбíльший.*

The **analytical (compound) superlative** is formed by adding the words **найбíльш/наймéнш** to the positive-degree form of the adjective: *розу́мний → найбíльш/наймéнш розу́мний.*

Superlative-degree adjectives change by gender, number, and case just like ordinary adjectives.

## 11. Вид дієслова (Aspect of the Verb)

### 11.1 Вид дієслова (Aspect of Verbs)

Most Ukrainian verbs have two forms: **недоко́наний вид** (imperfective) and **докóнаний вид** (perfective), which together make up an **aspectual pair**. Both members of an aspectual pair share the same lexical meaning, but the imperfective form does not indicate whether the action is *completed*, focusing instead on the process, while the perfective form emphasizes the action's completion and its result. Perfective verbs are never used in the present tense.

That said, a speaker can still use the imperfective form to signal that an action *was* completed, if they want to emphasize the *process* rather than the *result*: *Учóра я дивúлася дýже цікáвий фільм. – Хоч Мовец і закíнчив його́ дивúтися, alé він хóче зверну́ти нáшу увáгу на сáму дíю, на те, що він робúв, а не на результáт, на те, чим він закíнчив це роби́ти.* ("Yesterday I watched a very interesting film" — even though the speaker did finish watching it, they want to draw attention to the action itself, what they were doing, not the result, what they ended up doing.)

**Formation of the perfective infinitive** from an imperfective infinitive uses several strategies:

| Strategy | Недоко́наний вид | Докóнаний вид |
|---|---|---|
| 1. Adding a prefix | читáти, писáти, роби́ти | прочитáти, написáти, зроби́ти |
| 2a. Changing/dropping the suffix -ува-(-юва-) | купувáти, повторю́вати | купи́ти, повтори́ти |
| 2b. Changing the suffix -а-(-я-) | вивчáти, дозволя́ти | ви́вчити, дозво́лити |
| 2c. Changing the suffix -а-,-ва-,-та- | усміхáтися, розвивáти, розгортáти | усміхну́тися, розви́нути, розгорну́ти |
| 2d. Changing suffix -ва- | давáти | дáти |
| 2e. Changing suffix -а- | лягáти | ля́гти |
| 3. Consonant/vowel alternation | сиді́ти, крич́ати | сі́сти, кри́кнути |
| 4. Change of stress | вимі́ряти | ви́міряти |
| 5. Change of root (suppletive) | брáти, шукáти, говори́ти | взя́ти, знайти́, сказáти |

> [!note] Because these formation patterns are irregular and full of exceptions, it's more reliable to look up a verb's aspectual partner in the verb dictionary (see the "Таблиц́ях" table, source p. 259) than to try to derive it.

A small set of verbs **have no aspectual pair** at all:

| Ли́ше недоко́наного ви́ду | Ли́ше докóнаного ви́ду |
|---|---|
| коштувáти | завітáти |
| мáти | схаменути́ся |
| знáти | |
| сподівáтися | |

### 11.2 Минулий час: докóнаний і недоко́наний вид (Past Tense: Perfective and Imperfective Aspect)

Past-tense forms of both aspects are built the same way: to the stem of the corresponding infinitive (perfective or imperfective), add **-в** (masc.), **-ла** (fem.), **-ло** (neut.), or **-ли** (pl.).

**When to use imperfective vs. perfective past tense:**

| Imperfective expresses: | Perfective expresses: |
|---|---|
| 1) a **habitual action** (esp. with за́вжди, постíйно, звичáйно, зазвичáй, як прáвило, регуля́рно, чáсто, і́ноді, рíдко, ніко́ли, ...): *Дру́зі зустрічáлися в клубí.* | 1) a **one-time completed action** |
| 2) a **repeated action** (esp. with щодня́, щоти́жня, щомíсяця, щорóку, кóжного дня, ...разí): *Подру́ги щоти́жня роби́ли манікю́р.* | 2) a **finished action with a result** (esp. with уже́/вже, ще не..., наре́шті): *Подру́ги вже зроби́ли манікю́р цьо́го ти́жня.* |
| 3) a **prolonged action/process** (esp. with тодí, у той час, дóвго, від/до... до..., увéсь, цíлий, минýлого/мину́лí..., прóтягом, впродóвж): *Учóра він увéсь день диви́вся телевíзор.* | 3) a **sudden, immediate action** (esp. with рáптом, відрáзу/одрáзу, негáйно): *Рáптом дівчина поди́вилася на годи́нник.* |
| 4) **two simultaneous actions**: *Ко́ли Наталя чита́ла лист, Андрíй готувáв вечéрю.* | 4) **two consecutive actions**: *Ко́ли Наталя прочитáла лист, вони з Андрíєм повечéряли.* |
| 5) — | 5) a **one-time action that is a fact**, needing no repetition or time detail (esp. with вже/уже́): *Ти (вже) бáчив фільм "Повóдир"? Цікáва кни́жка, я (вже) її читáв.* |

### 11.4 Майбутній час: докóнаний і недоко́наний вид дієслова (Future Tense: Perfective and Imperfective Aspect of Verbs)

The imperfective future can take two parallel forms: (1) a **compound form** — **БУТИ (future tense) + imperfective infinitive** (бýду читáти); or (2) a **simple form**, built by adding the suffix **-М-** plus the ordinary conjugation-I present-tense personal endings to the full imperfective infinitive: читáти (imperfective infinitive) + -му/-меш/-ме/-мемо/-мете/-муть → читáтиму, читáтимеш... These two forms are equivalent in meaning, but the compound form is used more often in everyday speech and the simple (suffixed) form in more formal contexts.

The **perfective future** is formed by adding the ordinary present-tense personal endings directly to the perfective infinitive's stem: прочитá- (perfective infinitive stem) + -ю/-єш/-є/-ємо/-єте/-ють → прочитáю, прочитáєш...

**When to use imperfective vs. perfective future tense** — the same set of contrasts as for the past tense (habitual vs. one-time; repeated vs. completed-with-result; prolonged/process vs. sudden; two simultaneous vs. two consecutive actions), now projected into the future. New future-specific vocabulary illustrating the **necessity/obligation/permission/prohibition** category is also introduced here:

*Нам ТРЕБА багато читáти украї́нською мóвою.* ("We need to read a lot in Ukrainian.") *Їм СЛІД більше увáги приді́ляти грамáтиці.* ("They should pay more attention to grammar.") *Вам ПОТРІБНО вчи́ти більше слів.* ("You need to learn more words.") *Тобі́ НЕОБХІ́ДНО купи́ти дóбру кни́жку з грамáтики.* ("You must buy a good grammar book.") *Йому́ чáсто ДОВО́ДИТЬСЯ говори́ти украї́нською на робóті.* ("He often has to speak Ukrainian at work.")

The category of **permission/prohibition** is usually expressed with the predicative words **МОЖНА/НЕ МОЖНА** ("may/may not"), used in impersonal constructions after a noun/pronoun in the dative case: *Нам МОЖНА відвідувати бібліотéку безкошто́вно.* ("We may visit the library for free.") *Їм НЕ МОЖНА так чáсто ї́сти цуке́рки.* ("They may not eat candy so often.")

> [!note] However, when МОЖНА is used to make requests or ask about permission, two parallel constructions are possible: **МОЖНА + nominative + future tense** (Мóжна я піду́ гуля́ти?) or **МОЖНА + dative + infinitive** (Мóжна менí пiти́ гуля́ти?).

### 11.6 Вираження категорій необхідності/повинності, дозволу/заборони (Expressing the Categories of Necessity/Obligation and Permission/Prohibition)

The category of necessity/obligation in Ukrainian is often expressed with these predicative words: **ПОВИНЕН (ПОВИННА, ПОВИННЕ, ПОВИННІ), ЗОБОВ'ЯЗАНИЙ (-А, -Е, -І), СЛІД, ТРЕБА, ПОТРІ́БНО, НЕОБХІ́ДНО, МУ́СИТИ, МА́ТИ, ДОВО́ДИТИСЯ...**

Some of these are used in **two-part sentences** (with the subject in the nominative case): *Студе́нти ПОВИННІ вчáсно виконувати завда́ння.* ("Students should complete assignments on time.") *Студе́нти ЗОБОВ'Я́ЗАНІ склáсти і́спити в кінці́ семéстру.* *Студе́нти МУ́СЯТЬ відвідувати ле́кції.* *Студе́нти МА́ЮТЬ бага́то читáти.*

Others are used in **impersonal sentences** (after a noun/pronoun in the dative case), functioning as predicative words — see §12.2 below.

### 12.2 Давальний відмінок іменника та прикметника (Dative Case: Nouns and Adjectives)

The dative case marks **the addressee of an action** — who an action is done *for/to*. Masculine nouns have two parallel endings in the dative singular, **-у(-ю)** and **-ові(-еві)**; the **-ові(-еві)** form is felt as more conversational/lively and is preferred when several masculine nouns appear together in the dative in one sentence, to avoid repeating the -у(-ю) ending too many times.

| Gender | Nominative | Давáльний відмінок |
|---|---|---|
| Чолові́чий рід | рі́дний брат, мужні́й хло́пець, Андрі́й | рі́дному брáтові/брáту, мужнь́ому хло́пцеві/хлóпцю, Андрі́єві/Андрі́ю |
| Жіно́чий рід | рі́дна мáма, сусі́дня ву́лиця | рі́дній мáмі, сусі́дній ву́лиці |
| Сере́дній рід | вели́ке вікнó, лі́тнє сóнце | вели́кому вікнý, лі́тньому сóнцю |
| Множина́ | дóбрі подру́ги, рі́дні племі́нниці | дóбрим подрý­гам, рі́дним племі́нницям |

The same stem-change rules already introduced under the genitive and locative sections apply (г→з, х→с before an -і ending, e.g. подрýга → подрýзі; свекрýха → свекрýсі).

> [!note] The noun **МАТИ** ("mother") has a special dative form: **МА́ТЕРІ**.

**Use of the dative case:**

1. To express the **addressee of an action** (dative = "for" + genitive equivalent) — *Ми купи́ли подру́зі кни́жку.* = *Ми купи́ли кни́жку для подру́ги.*
2. After certain verbs (each shown as its imperfective/perfective aspectual pair) + dative case:

   | Недоко́наний вид | Докóнаний вид |
   |---|---|
   | телефонувáти | зателефонувáти |
   | дзвони́ти | подзвони́ти |
   | говори́ти | сказáти |
   | розповідáти | розповіс́ти |
   | відповідáти | відпові́сти |
   | дя́кувати | подя́кувати |
   | пояс́нювати | поясни́ти |
   | обіцяти | пообіцяти |
   | читáти | прочитáти |
   | показувáти | показáти |
   | подóбатися | сподо́батися |
   | купувáти | купи́ти |
   | плати́ти | заплати́ти |
   | дарувáти | подарувáти |
   | давáти | дáти |
   | посилáти | послáти |
   | передавáти | передáти |
   | готувáти | приготувáти |
   | співáти | заспівáти |
3. In certain constructions: (a) about **age** — Дáтельний + рік/рóки/рокíв: *Андрі́єві 28 рóків, а Наталí 22 рóки.* (b) about **preferences** — Дáтельний + подóбається/подóбаються, сподóбався/сподóбалася...: *Андрі́єві подóбається грáти у футбóл, а Наталí подóбається танцюва́ти.* (c) about **necessity, permission, prohibition, advice** — Дáтельний + трéба/потрí́бно/мóжна/не мóжна/слід: *Андрі́єві не мóжна бáчити Наталю у весі́льній сýкні до весí́лля.* (d) about **a person's state/condition** — Дáтельний + adverb (хóлодно, гарячé, ці́каво, ну́дно, вéсело, су́мно, приéмно, добрé, стрáшно...): *Андрí́єві су́мно без Наталí. Дівчáтам стрáшно виходи́ти зáмiж?*

### 12.3 Зворотний займенник СЕБЕ (The Reflexive Pronoun СЕБЕ)

Ukrainian has just one reflexive pronoun, **СЕБЕ**, used to mark that the action's effect is directed back at the person performing it. This pronoun has a single form across all genders, persons, and numbers.

| Відмінок | Безприйме́нникова форма | Приймéннико́ва форма |
|---|---|---|
| Назви́вний відмінок | — | — |
| Родо́вий відмінок | себé | до себé |
| Давáльний відмінок | собí | — |
| Знахі́дний відмінок | себé | про себé |
| Ору́дний відмінок | собóю | з собóю |
| Місцéвий відмінок | — | у/на собí |

### 12.4 Знахідний відмінок (істоти) (Accusative Case: Animate)

In the accusative case, nouns denoting **animate beings** (people, animals) take different forms from those denoting inanimate objects. Unlike inanimate nouns, animate nouns change form in **all genders**.

| Gender | Nominative | Знахі́дний відмінок |
|---|---|---|
| Чолові́чий рід | дорогúй син, коли́шній хлóпець | дорогóго си́на, коли́шнього хлóпця |
| Жіно́чий рід | кохáна дóчка, коли́шня письме́нниця | кохáну дóчку, коли́шню письме́нницю |
| Множина́ (ч.р.) | найкрáщі дрýзі | найкрáщих друзí́в |
| Множина́ (ж.р.) | найкрáщі подрýги | найкрáщих подрýг |

**Summary rule**:

| Category | Знахі́дний відмінок (istoty) equals... |
|---|---|
| Masculine animate | masculine genitive singular |
| Feminine animate | feminine inanimate accusative singular |
| Plural (any gender) | genitive plural |

**Use of the accusative case** to express the object of an action:

1. After certain **transitive verbs**: мáти, чýти, слýхати, бáчити, люби́ти, ненави́діти, чекáти, розумí́ти, знáти, вчи́ти/навчáти, пам'ята́ти, вітáти, зустрí́ти, проси́ти + accusative case.
2. After certain **prepositions**: про + accusative (Андрі́й дýмає прó Наталю — "Andriy is thinking about Natalia"); на + accusative (Андрí́й ди́виться на Наталю — "Andriy is looking at Natalia").
